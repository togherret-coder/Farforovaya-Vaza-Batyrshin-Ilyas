# GenAIGD_SpaceStationEvo

## О проекте
Космическая стратегия с фокусом на эволюцию единственной станции. 
Вдохновлена играми вроде "FTL" и "Starbreak".

*   **Жанр:** Стратегия в реальном времени с элементами roguelite.
*   **USP (Уникальность):** Игрок не строит флот, а развивает одну базу, перерабатывая врагов на запчасти.
*   **Целевая аудитория:** Любители научной фантастики, сложных стратегий и экспериментов с билдами.
*   **Платформы:** PC (Windows, macOS).
